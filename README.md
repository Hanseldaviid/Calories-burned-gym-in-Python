# Calories-burned-gym-in-Python
Basic code made in Python to calculate the calories burned in each exercise. 

A Python console application that helps users track their daily workout routines, calculate burned calories per exercise session, and evaluate their overall performance using interactive control flow logic.

## 🚀 Features

* **Interactive Menu Navigation:** Built using Python's `match-case` statement for clean option selection.
* **Input Validation & Error Handling:** Utilizes `while True` loops and `try-except` blocks (`ValueError`) to prevent invalid entries (e.g., negative numbers or string inputs).
* **Calorie Calculation Rules:** Custom calorie multipliers tailored to specific exercise types based on duration and session intensity:
  * 🏃 **Running:** 10 kcal/min
  * 🚴 **Cycling:** 5 kcal/min
  * 🏋️ **Lifting Weights:** 8 kcal/min
* **Real-time Performance Feedback:** Evaluates calorie output per exercise and gives immediate motivational encouragement.
* **Workout Summary:** Displays total completed exercises and cumulative calories burned upon completion.

## 🛠️ Concepts Applied

* Control Flow Structures (`if-elif-else`, `match-case`)
* Iteration Loops (`for`, `while`) & Loop Control (`break`)
* Variable Scope & Accumulators
* Exception Handling (`try-except`)
